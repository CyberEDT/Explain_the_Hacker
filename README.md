# 🔴 ETH — Explain The Hacker

> **See the attack through the attacker's eyes.**

ETH (Explain The Hacker) is an **Attacker Intelligence Platform** that transforms technical security findings into attacker-perspective intelligence. Rather than simply displaying ports, services, or misconfigurations, ETH explains **how an attacker thinks, what they see, why they act, and how an attack may progress** through interactive visualizations, attack narratives, and intelligence-driven analysis.

Designed for cybersecurity students, professionals, researchers, educators, and law enforcement, ETH bridges the gap between technical findings and real-world adversary behavior.

---

# 🚀 Overview

Traditional security tools answer:

> **"What was found?"**

ETH answers:

> **"What would an attacker do with it?"**

Using attacker-centric reasoning, MITRE ATT&CK mappings, the Cyber Kill Chain, and a growing intelligence knowledge base, ETH transforms raw technical inputs into understandable attack intelligence.
