# Explain The Hacker — CyberEDT

> **Simulate, visualize, and understand real-world attack chains.**
> A powerful, browser-based threat simulation engine that maps exposed infrastructure, misconfigurations, and raw log data directly to MITRE ATT&CK tactics, generating highly accurate Attack Chains and Indicators of Compromise (IOCs).

---

## 🔥 Key Features

- 🎯 **Advanced Threat Correlation Engine** — Dynamically correlates user inputs to generate hyper-realistic threat vectors (e.g., correlating Port 445 + "unpatched" directly to an EternalBlue MS17-010 exploitation narrative).
- 📊 **Dynamic MITRE ATT&CK Mapping** — Automatically maps generated attack chains to specific 7-phase MITRE techniques (T1595, T1210, T1053) based on input complexity.
- 🔐 **Privacy-First Persistent History** — Automatically saves your recent threat analyses natively to the browser's 5MB `localStorage` utilizing an AES/XOR cipher. Operates strictly under user consent via a global privacy banner.
- 🔍 **Robust Input Parsing** — Supports up to 50 ports and 20 misconfigurations with regex-powered categorization for cloud leaks, credential stuffing, and unpatched infrastructure.
- 🛡️ **Intelligent Mitigations** — Provides prioritized, emergency defense recommendations sorted by severity and tailored to the exact threat vector.
- 📈 **Sleek Data Visualization** — Recharts-powered Risk Gauges, MITRE Stage Bars, and interactive Live Attack Chain flows.
- 🚀 **SEO & Performance Optimized** — Fully equipped with Canonical URLs, Open Graph Meta tags, Twitter Cards, and Strict Content-Security-Policies tailored for `www.cyberedt.com`.

## ⚡ Quick Start

```bash
# 1. Clone the repository and install dependencies
npm install

# 2. Start the Vite development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## ⚙️ Environment Variables

Copy `.env.example` to `.env` and configure:

```bash
cp .env.example .env
```

| Variable | Default | Description |
|----------|---------|-------------|
| `VITE_USE_MOCK` | `true` | Set to `false` to use the real live CyberEDT API endpoint. |
| `VITE_API_BASE_URL` | `https://api.cyberedt.com/v1` | Backend API base URL. |

> **Security Note**: Never commit your real `.env.production` files.

## 🔒 Security Posture

- **Client-Side Obfuscation**: All persistent simulation history stored in `localStorage` is completely obfuscated using a Base64 XOR cipher to prevent plain-text exposure in browser Developer Tools.
- **XSS Prevention**: Every single text node generated by the AI/engine is rigorously sanitized via custom `stripHtml` and `stripScripts` utilities before being mounted to the DOM. Zero usage of `dangerouslySetInnerHTML`.
- **Strict CSP**: A tight Content-Security-Policy restricts external script execution and strictly defines `api.cyberedt.com` as the only trusted data source.
- **Privacy Consent**: Full GDPR/CCPA compliance regarding local browser storage via an explicit, un-intrusive consent banner.
